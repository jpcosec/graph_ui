# Auto Layout

This example demonstrates how to automatically arrange nodes. It
introduces a reusable `useAutoLayout` hook and showcases three popular
layout engines that you can switch between at runtime:
<a href="https://github.com/dagrejs/dagre">dagre </a>,
<a href="https://github.com/d3/d3-hierarchy">d3-hierarchy </a>,
and
<a href="https://github.com/kieler/elkjs">elk </a>.
