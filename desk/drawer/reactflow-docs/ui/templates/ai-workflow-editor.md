# AI Workflow Editor

The AI Workflow Editor template is a Next.js template for getting
started quickly with an AI workflow app. It’s based on our
<a href="/ui/templates/workflow-editor">workflow editor template</a>,
<a href="https://ai-sdk.dev/">AI SDK </a>
and
<a href="https://ui.shadcn.com/">shadcn/ui </a>.

## Tech Stack

-   **React Flow UI**: The project uses
    <a href="/ui">React Flow UI</a>
    for the nodes. These components are designed to help you quickly get
    up to speed on projects.

-   **shadcn CLI**: The project uses
    <a href="https://ui.shadcn.com/docs/cli">shadcn CLI </a>
    to manage UI components. This tool builds on top of
    <a href="https://tailwindcss.com/">Tailwind CSS </a>
    and
    <a href="https://ui.shadcn.com/">shadcn/ui </a>
    components, making it easy to add and customize UI elements.

-   **AI SDK**: The template uses
    <a href="https://ai-sdk.dev/">AI SDK </a>
    to provide AI-powered features within the workflow editor.

-   **State Management with Zustand**: The AI workflow editor template
    uses Zustand for state management, providing a simple and efficient
    way to manage the state of nodes, edges, and other workflow-related
    data.
