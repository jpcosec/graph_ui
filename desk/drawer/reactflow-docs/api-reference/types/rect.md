# Rect

<a href="https://github.com/xyflow/xyflow/blob/f0ce2c876d8688e13632bc86286cf857f86dead6/packages/system/src/types/utils.ts/#L39-L40">Source on GitHub </a>

The `Rect` type defines a rectangle in a two-dimensional space with
dimensions and a position.

| Name                                                                                                                                                                                                                                                                            | Type     | Default |
|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------|---------|
| `width`   | `number` |         |
| `height` | `number` |         |
| `x`           | `number` |         |
| `y`           | `number` |         |
