# EdgeMarker

<a href="https://github.com/xyflow/xyflow/blob/main/packages/system/src/types/edges.ts/#L70-L78">Source on GitHub </a>

Edges can optionally have markers at the start and end of an edge. The
`EdgeMarker` type is used to configure those markers! Check the docs for
<a href="/api-reference/types/marker-type"><code dir="ltr">MarkerType</code></a>
for details on what types of edge marker are available.

## Fields

| Name                                                                                                                                                                                                                                                                                      | Type                                   | Default |
|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------|---------|
| `type`               | `MarkerType | "arrow" | "arrowclosed"` |         |
| `color`             | `string | null`                        |         |
| `width`             | `number`                               |         |
| `height`           | `number`                               |         |
| `markerUnits` | `string`                               |         |
| `orient`           | `string`                               |         |
| `strokeWidth` | `number`                               |         |
