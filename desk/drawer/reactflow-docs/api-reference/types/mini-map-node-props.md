# MiniMapNodeProps

<a href="https://github.com/xyflow/xyflow/blob/487b13c9ad8903789f56c6fcfd8222f9cb74b812/packages/react/src/additional-components/MiniMap/types.ts/#L60">Source on GitHub </a>

The MiniMapNodeProps type defines the props for nodes in the MiniMap
component. This is only relevant if you pass a custom node type to the
MiniMap.
