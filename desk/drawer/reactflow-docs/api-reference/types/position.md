# Position

<a href="https://github.com/xyflow/xyflow/blob/main/packages/system/src/types/utils.ts/#L1">Source on GitHub </a>

While
<a href="/api-reference/types/panel-position"><code dir="ltr">PanelPosition</code></a>
can be used to place a component in the corners of a container, the
`Position` enum is less precise and used primarily in relation to edges
and handles.

```tsx
export enum Position {
  Left = 'left',
  Top = 'top',
  Right = 'right',
  Bottom = 'bottom',
}
```
