# KeyCode

<a href="https://github.com/xyflow/xyflow/blob/main/packages/system/src/types/general.ts#L155">Source on GitHub </a>

The `KeyCode` type is used to specify keyboard key codes or
combinations, such as deleting nodes or enabling multi-selection. It can
be a single string or an array of strings representing key codes.

```tsx
type KeyCode = string | Array<string>;
```
