# EncodingRules

## Answer

EncodingRules is for the L2 canvas rendering code and for operators who need the graph to communicate structure visually. Components that draw edges and node shells consume the resolved styles, while sidebar controls and saved views manage which rule set is active. It serves humans reading the graph and frontend code applying the visual language.
