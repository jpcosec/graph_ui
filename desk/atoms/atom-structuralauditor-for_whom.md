# StructuralAuditor

## Answer

It is for graph_ui consumers that need structural status attached to nodes, such as tests or downstream code that wants to display or inspect compliance cues. It supports the editor and related tooling by preparing annotated graph data. It is not a direct user-facing screen by itself.
