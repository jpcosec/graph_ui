# L2Canvas

## Answer

L2Canvas is the interactive canvas layer of the React editor. It owns the shared editing surface built on ReactFlow: canvas rendering, sidebar controls, inspectors, command menu, layout hooks, encoding, relation filtering, and interaction wiring to the stores. It is the middle layer between page orchestration (L1) and per-node/per-edge renderers (L3).
