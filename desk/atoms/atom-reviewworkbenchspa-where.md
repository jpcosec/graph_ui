# ReviewWorkbenchSPA

## Answer

The SPA runtime is described in `docs/specs/deployment.runtime.yml` as `review-workbench SPA (React/Vite bundle)`. Its browser bootstrap code is at `apps/review-workbench/src/App.tsx`, and its local server entry point is the `dev` script in `apps/review-workbench/package.json`. Those are the exact repository locations that define ReviewWorkbenchSPA today.
