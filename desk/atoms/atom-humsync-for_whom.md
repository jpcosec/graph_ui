# HumSync

## Answer

HumSync serves developers and test runs that want the HumBody fixture to reflect source data without manual editing. It also serves the mounted HumBody page indirectly, because that page consumes the generated file it is meant to refresh. It is not an operator-facing persistence mechanism.
