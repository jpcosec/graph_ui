# ReviewWorkbenchSPA

## Answer

ReviewWorkbenchSPA serves the human using graph_ui in a browser, whether that is a developer, tester, or eventual operator. It also serves frontend development by being the mounted runtime that exercises data loading, state, and interaction layers together. It is the consumer-facing UI surface, not the backend integration seam.
