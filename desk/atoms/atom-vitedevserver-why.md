# ViteDevServer

## Answer

ViteDevServer exists so developers can interact with graph_ui in a browser, iterate on the UI quickly, and run browser-based user flows against a live app. Without it, the React editor would not have a convenient local runtime surface. It is the short feedback loop for frontend work.
