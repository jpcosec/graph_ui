# ReviewWorkbenchSPA

## Answer

ReviewWorkbenchSPA exists to present the editor interface, its pages, and its runtime wiring inside the browser. It is the container that turns contracts, stores, queries, and canvas components into an interactive tool a person can use. Without it, graph_ui would remain only code modules and specs with no running UI surface.
