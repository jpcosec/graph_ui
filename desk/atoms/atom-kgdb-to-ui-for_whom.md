# kgdb_to_ui_graph

## Answer

It is for graph_ui backend code or integrations that need to consume kgdb data through the graph_ui contract. It specifically serves the target live-data path from kgdb into the editor. Operators benefit indirectly because it prepares the graph they would edit, but they do not call it themselves.
