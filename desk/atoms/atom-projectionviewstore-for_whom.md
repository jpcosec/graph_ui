# ProjectionViewStore

## Answer

ProjectionViewStore is for the views-management UI and for operators who want to save and reload named ways of seeing the graph. Frontend code uses it to persist layout and encoding choices between sessions, while humans use it to return to familiar visual projections. It serves view orchestration, not graph editing semantics.
