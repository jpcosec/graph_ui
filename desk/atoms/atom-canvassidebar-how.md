# CanvasSidebar

## Answer

It reads sidebarOpen and toggleSidebar from the UI store and switches between a compact opener button and the full sidebar panel. When open, it renders the deck header, an optional top panel, a small status card, and accordion sections that host the six sidebar subsections.
