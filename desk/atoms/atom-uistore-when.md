# UiStore

## Answer

UiStore is used whenever the operator interacts with editor chrome rather than raw graph data. That includes switching browse or edit modes, toggling the sidebar, applying or clearing filters, choosing a layout strategy, selecting a named view, opening delete confirmation, and invoking the command dialog. It is the live session state for day-to-day canvas interaction.
