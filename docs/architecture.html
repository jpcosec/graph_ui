Data Load Flow (current)

How the app loads data today (static baked fixture).

sequencetype:sequence
      sequenceDiagram
          participant App
          participant HumBodyPage
          participant Adapter
          participant MockData
          participant GeneratedAst
          participant GraphStore
          App->>HumBodyPage: mount default page
          HumBodyPage->>Adapter: buildHumViewGraph(mode)
          Adapter->>MockData: read humBodyModel
          MockData->>GeneratedAst: import generatedHumAstFiles/Forms
          GeneratedAst->>MockData: static TS array (frozen fixture)
          Adapter->>HumBodyPage: nodes + edges
          HumBodyPage->>GraphStore: loadGraph(nodes, edges)
          GraphStore->>HumBodyPage: in-memory draft graph

Data Load + Save Flow (target, over kgdb)

Target read/write flow directly over kgdb.

sequencetype:sequence
      sequenceDiagram
          actor Operator
          participant DataProvider
          participant KgdbAdapter
          participant Kgdb
          participant GraphStore
          participant Canvas
          Operator->>DataProvider: open editor
          DataProvider->>Kgdb: fetch GraphSnapshot
          Kgdb->>KgdbAdapter: GraphSnapshot
