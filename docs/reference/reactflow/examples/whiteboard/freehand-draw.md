# Freehand Draw

This example demonstrates how to implement freehand drawing capabilities
in your React Flow application. Users can draw smooth curves on the
pane, which can be useful for annotations or sketching around existing
nodes. Drawings get converted into custom nodes that can be styled and
manipulated like regular nodes.
