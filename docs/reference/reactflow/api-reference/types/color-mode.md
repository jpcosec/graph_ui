# ColorMode

<a href="https://github.com/xyflow/xyflow/blob/main/packages/system/src/types/general.ts">Source on GitHub </a>

The `ColorMode` type defines the available color modes for the ReactFlow
component. This can be used to control the theme of the flow diagram.

```tsx
export type ColorMode = 'light' | 'dark' | 'system';
```
