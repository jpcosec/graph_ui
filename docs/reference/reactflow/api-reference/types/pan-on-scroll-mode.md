# PanOnScrollMode

<a href="https://github.com/xyflow/xyflow/blob/main/packages/system/src/types/general.ts#L166">Source on GitHub </a>

The `PanOnScrollMode` enum controls the panning behavior of the viewport
when the user scrolls. Choose `Free` for unrestricted panning,
`Vertical` for up-and-down only, or `Horizontal` for left-and-right
only.

```tsx
enum PanOnScrollMode {
  Free = 'free',
  Vertical = 'vertical',
  Horizontal = 'horizontal',
}
```
