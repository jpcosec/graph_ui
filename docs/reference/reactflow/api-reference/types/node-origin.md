# NodeOrigin

The origin of a Node determines how it is placed relative to its own
coordinates. `[0, 0]` places it at the top left corner, `[0.5, 0.5]`
right in the center and `[1, 1]` at the bottom right of its position.

```tsx
export type NodeOrigin = [number, number];
```
